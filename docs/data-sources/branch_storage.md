# neon_branch_storage (Data Source)

Reads the S3-compatible connection details for branchable object storage on a Neon branch.

## Example Usage

```terraform
data "neon_branch_storage" "this" {
  project_id = "cool-moon-42"
  branch_id  = "br-cool-moon-42"
}

output "s3_endpoint" {
  value = data.neon_branch_storage.this.s3_endpoint
}

output "region" {
  value = data.neon_branch_storage.this.region
}

output "force_path_style" {
  value = data.neon_branch_storage.this.force_path_style
}
```

- `force_path_style` (Boolean) Whether the S3 client must use path-style addressing (bucket-in-path rather than virtual-hosted subdomain). Always true for Neon branch storage.
