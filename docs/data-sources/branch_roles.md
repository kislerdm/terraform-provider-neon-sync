# neon_branch_roles (Data Source)

Lists PostgreSQL roles in a Neon branch.

## Example Usage

```terraform
data "neon_branch_roles" "this" {
  project_id = var.project_id
  branch_id  = var.branch_id
}

variable "project_id" {
  type = string
}

variable "branch_id" {
  type = string
}

output "roles" {
  value = data.neon_branch_roles.this.roles
}
```

## SDK v2 Migration

Remove any configured `roles` blocks before upgrading.
`roles` is now a read-only list; expressions such as `roles[0].name` remain unchanged.
Back up Terraform state and the original configuration before changing provider versions.
The ID remains `<project_id>/<branch_id>/roles`, and an omitted protection flag still returns `true`.
This data source returns role names and protection flags, never passwords.
