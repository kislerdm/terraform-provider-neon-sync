# neon_trigger (Resource)

Manages a Neon trigger (Function invocation on a schedule or after a branch-bucket object upload).

## Example Usage

```terraform
resource "neon_project" "example" {
  name      = "foo"
  region_id = "aws-us-east-2"
}

# schedule trigger: invokes the Function on a cron schedule.
# function_slug is a free-form string; pair with neon_function via depends_on if
# you need Terraform to manage ordering.
resource "neon_trigger" "schedule" {
  project_id    = neon_project.example.id
  branch_id     = neon_project.example.default_branch_id
  name          = "every-five-minutes"
  type          = "schedule"
  function_slug = "my-handler"
  schedule = {
    cron = "*/5 * * * *"
  }
}

# storage_object_created trigger: invokes the Function when an object is
# uploaded to the bucket. Requires neon_bucket to exist.
resource "neon_bucket" "example" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.default_branch_id
  name       = "uploads"
}

resource "neon_trigger" "storage" {
  project_id    = neon_project.example.id
  branch_id     = neon_project.example.default_branch_id
  name          = "on-upload"
  type          = "storage_object_created"
  function_slug = "my-handler"
  storage_object_created = {
    bucket_name = neon_bucket.example.name
    prefix      = "incoming/"
  }
  depends_on = [neon_bucket.example]
}
```

## Schema

### Required

- `branch_id` (String) The Neon branch ID.
- `function_slug` (String) The branch-local Function slug resolved when an occurrence is consumed.
- `name` (String) Human-readable trigger name. Unique among triggers visible on the branch.
- `project_id` (String) The Neon project ID.
- `type` (String) Trigger type discriminator. One of `schedule` or `storage_object_created`.

### Optional

- `enabled` (Boolean) Whether future occurrences should fire the trigger.
- `function_path` (String) Path passed to the target Function. Defaults to `/`.
- `schedule` (Attributes) (see [below for nested schema](#nestedatt--schedule))
- `storage_object_created` (Attributes) (see [below for nested schema](#nestedatt--storage_object_created))

### Read-Only

- `id` (String) Composite ID of the form <project_id>/<branch_id>/<trigger_id>.
- `inherited` (Boolean) True when the effective configuration was authored on an ancestor branch.
- `next_run_at` (String) Next scheduled occurrence as an RFC 3339 UTC timestamp. Null while disabled or inherited and not explicitly enabled on this branch.
- `trigger_id` (String) Opaque, server-minted trigger ID.
- `version` (Number) Monotonic configuration version.

## Import

The Neon Trigger cannot be imported because the server mints `trigger_id` on create. Re-author the trigger in your Terraform configuration to manage it.
